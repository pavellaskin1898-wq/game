# WASTELAND 2 — Fallout-like FPS в браузере

Мини-шутер от первого лица в духе Fallout 2, целиком на чистом JS (raycasting-движок,
как в Wolfenstein 3D). Никаких зависимостей и сборки.

## Запуск
```bash
# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Как играть
- Цель: найти **3 модуля управления** в Убежище 13 и выбраться через выход (E на миникарте).
- Управление: WASD — ходьба, мышь — обзор, ЛКМ — огонь, R — перезарядка,
  Shift — бег (тратит AP), 1/2 — смена оружия, Esc — пауза.
- Враги: когти смерти (ближний бой) и рейдеры (стреляют).
- Лут: стимпаки (+HP), Ядер-Кола (+HP, +радиация), патроны, крышки ₪.
- HUD в стиле Pip-Boy: HP / AP / радиация, кредиты, боезапас, лог событий, миникарта, CRT-развёртка.

## Файлы
- `index.html` — разметка и экраны
- `style.css` — Pip-Boy HUD и CRT-эффект
- `game.js` — движок: карта, raycasting, ИИ, оружие, звук (WebAudio, без файлов)
